# StockManager

## Overview
A desktop application designed to manage product inventory, track stock quantities, and calculate total asset values efficiently.

## Technologies
C#, .NET 10, Git, GitHub

## Project Status
In active development (initial planning and core architecture stage).

## Planned Features
* Add products
* Edit products
* Delete products
* Search products
* Stock quantity tracking
* Inventory value calculation
* Database storage
* Graphical user interface
